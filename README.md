# Video FPS & Resolution Display

Webページで再生中の動画のFPSと解像度をリアルタイム表示するChrome拡張機能です。

## 機能

- **FPS表示**: 動画の実際のフレームレートをリアルタイムで表示
- **解像度表示**: 動画の幅×高さを表示
- **ON/OFF切り替え**: 拡張機能アイコンをクリックして表示の有効/無効を切り替え
- **カスタマイズ**: 表示位置（左上/右上/左下/右下）と文字色を設定可能

## インストール方法

1. Chromeで `chrome://extensions/` を開く
2. 「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`fps`）を選択

## 使い方

1. 動画が再生されているWebページを開く
2. 画面右上（デフォルト）にFPSと解像度が表示されます
3. 拡張機能アイコンをクリックして表示のON/OFFを切り替え
4. 「設定を開く」から表示位置と文字色を変更できます

## 技術仕様

- FPS計測には `requestVideoFrameCallback` API（対応ブラウザ）または `getVideoPlaybackQuality` のフォールバックを使用
- YouTube、ニコニコ動画、その他HTML5動画に対応
